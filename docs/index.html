Twelve sharp tools, one calm interface

T-Rex doesn't reimplement conversion. It orchestrates best-in-class engines — FFmpeg, ImageMagick, LibreOffice, Pandoc, Tesseract, PyMuPDF/qpdf and more — behind a single GTK4/libadwaita interface: an async task queue, presets, and a dashboard instead of a dozen man pages. Every engine is optional; features light up when it's installed.

Under the hood

Each media family gets the engine that does it best.

FFmpegVideo & audio: convert, trim, compress, concat, mix, GIF
ImageMagickImage conversion, operations, and montage
LibreOfficeThe document matrix — headless docx/odt/xlsx/pptx/pdf and more
PyMuPDF · qpdfThe PDF toolbox: render, restructure, encrypt, compare
TesseractOCR to searchable PDF, txt, and hOCR
PandocEbooks & markup conversion
Inkscape · potraceSVG render & bitmap-to-vector trace
qrencode · zbarQR & barcode generate and decode
ExifToolMedia metadata: read, strip, edit
Python 3.11+ · GTK4 · libadwaitaThe native application shell, MIT-licensed

Every engine is a soft dependency: the app runs without it, the matching features switch off gracefully, and the Dashboard's Engines panel shows live availability.

Installing on Fedora

1

Grab the RPM from the latest release & install

sudo dnf install ./t-rex-converter-*.noarch.rpm
2

Add FFmpeg for video & audio (pick one)

sudo dnf install ffmpeg-free
# or the full ffmpeg from RPM Fusion
3

Optional: the rest of the engine pack

sudo dnf install ImageMagick libreoffice-writer \
    libreoffice-impress libreoffice-calc qpdf \
    tesseract pandoc qrencode zbar inkscape \
    potrace perl-Image-ExifTool

Running from source instead? git clone the repo and ./run-gtk.sh — see the README for the GTK4 prerequisites.
